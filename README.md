# Digital Curator — Kiro 代码能力实验项目

这是一个实验性项目，用于实测 [Kiro](https://kiro.dev) AI IDE 的代码还原能力。目标是将 Figma 设计稿 1:1 还原为可运行的 Next.js 网站。

## 设计稿

Figma 地址：[Blog & Community Design](https://www.figma.com/design/kHsZAdaPvHKdo0kWeyx5xl/Blog--Community-?node-id=1-3)

## 技术栈

- [Next.js](https://nextjs.org) (App Router)
- TypeScript
- Tailwind CSS

## 本地运行

```bash
npm install
npm run dev
```

打开 [http://localhost:3000](http://localhost:3000) 查看效果。

## 实验目的

验证 Kiro 能否通过读取 Figma 设计稿，自动生成高还原度的前端页面代码，包括布局、样式、组件拆分等。
